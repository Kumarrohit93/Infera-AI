# Infera AI — Member Panel

Infera AI is an enterprise B2B SaaS platform that enables organizations to securely manage internal documents and access AI-powered, document-grounded knowledge.

The Member Panel provides employees with an interface to access the platform and interact with organizational knowledge.

## 🚀 Tech Stack

- **Frontend:** React.js, Vite, JavaScript
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Animations:** Framer Motion
- **Package Manager:** NPM
- **Version Control:** Git & GitHub

## 🛠️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Kumarrohit93/Infera-AI.git
```

### 2. Navigate to the Member Frontend

```bash
cd Infera-Member-Frontend
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run Development Server

```bash
npm run dev
```

### 5. Create Production Build

```bash
npm run build
```
